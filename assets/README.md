# Ảnh của dự án

| File | Dùng ở đâu | Kích thước nên dùng |
|---|---|---|
| `logo.png` | Đầu README, trang web | 512×512, nền trong suốt |
| `logo-icon.png` | Favicon, avatar GitHub | 256×256, bản đơn giản |
| `banner.png` | Ảnh bìa README | 1280×640 |

Bản đơn giản (rùa + rắn, không có bàn cờ) dùng cho icon nhỏ vì ở 32px thì hoạ
tiết mai rùa và lưới bàn cờ sẽ nhoè thành một khối.
